# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an Astro + Vite static blog from the local `posts/` archive, with protected static encryption for `posts/禁止外传/**`, search, friend links, comments, and Vercel-compatible static deployment.

**Architecture:** Use a custom content build pipeline instead of Astro Content Collections because the archive has irregular frontmatter, Chinese paths, deep directories, and protected content. Public posts generate normal static metadata and routes; protected posts use opaque slugs and encrypted JSON for private metadata and body content. Astro renders the public shell, pages, and article layout, while client scripts handle protected unlock, on-demand decryption, search toggles, Mermaid rendering, and giscus loading.

**Tech Stack:** Astro, Vite, TypeScript, pnpm, Web Crypto API, Markdown/remark/rehype pipeline, Pagefind or MiniSearch, giscus, Vercel static deployment.

---

## 0. Implementation Rules

- Do not move or rewrite the source `posts/` archive.
- Do not output plaintext protected body, protected title, protected source path, protected category, or protected excerpt into `dist/`.
- Keep browser routes ASCII-only.
- Use `pnpm` for package management.
- Prefer small focused modules over a large build script.
- After each task, run the smallest meaningful verification.
- Commit after each complete task if the working tree is in a good state.

Responsibilities:

- `src/content/*`: Node-side content indexing, slugging, markdown parsing, encryption, and generated data writing.
- `scripts/build-content.ts`: CLI entrypoint that reads `posts/` and `friends-graph.json`, then writes `public/generated/*`.
- `src/pages/*`: Astro route pages.
- `src/components/*`: Reusable UI pieces.
- `src/client/*`: Browser-only scripts for unlock state, decryption, search, protected index hydration, and Mermaid.
- `public/generated/*`: Generated artifacts. They can be committed or regenerated during build; decide after the first implementation pass.
